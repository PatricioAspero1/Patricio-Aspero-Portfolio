# Radarr

**Type:** LXC Container  
**Host:** Prometheus  
**Resources:** 1 vCPU / 1 GB RAM  
**Role:** Movie Library Management

## Overview

Radarr provides automated movie library management within my self-hosted
media environment.

The service integrates with the other components of the application stack
while accessing shared media storage through the Prometheus host.

Running Radarr in a dedicated container provides application isolation and
allows the service to be maintained independently.

## Skills & Experience

- LXC administration
- Linux permissions
- Shared storage
- API-based service integration
- Application automation
- Network troubleshooting
