# Sonarr

**Type:** LXC Container  
**Host:** Prometheus  
**Role:** Television Library Management

## Overview

Sonarr provides automated television library management within my
self-hosted media environment.

The service integrates with other components of the application stack,
including Prowlarr and qBittorrent, while using shared storage hosted
by Prometheus.

Running Sonarr in its own LXC container provides application isolation
and allows the service to be maintained, updated, and troubleshot
independently.

- LXC administration
- Linux permissions
- Shared storage
- API-based service integration
- Application automation
- Service-to-service networking
