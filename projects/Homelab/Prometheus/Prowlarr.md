# Prowlarr

**Type:** LXC Container  
**Host:** Prometheus  
**Resources:** 1 vCPU / 1 GB RAM  
**Role:** Centralized Indexer Management

## Overview

Prowlarr provides centralized indexer management for applications within my
self-hosted media stack.

Rather than configuring integrations separately within each application,
Prowlarr provides a centralized service that communicates with applications
such as Sonarr and Radarr.

## Skills & Experience

- Linux service administration
- LXC containerization
- API integration
- Service-to-service networking
- Centralized application configuration
- Troubleshooting distributed services
