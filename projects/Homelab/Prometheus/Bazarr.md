# Bazarr

**Type:** LXC Container  
**Host:** Prometheus  
**Resources:** 1 vCPU / 1 GB RAM  
**Role:** Subtitle Management

## Overview

Bazarr provides automated subtitle management and integrates with the
media-management services running elsewhere on Prometheus.

It operates as an independent container while sharing access to the media
storage required by the broader application stack.

## Skills & Experience

- LXC administration
- Application integration
- Shared storage
- Linux permissions
- Service-to-service communication
