# qBittorrent

**Type:** LXC Container  
**Host:** Prometheus  
**Resources:** 2 vCPUs / 4 GB RAM  
**Role:** Containerized Download Client

## Overview

qBittorrent runs as a dedicated Linux container within my self-hosted
application environment.

The service integrates with other media-management applications while
accessing shared storage through a bind mount from the Prometheus host.

Running the application independently provides isolation from both the
Proxmox host and the other application services.

## Skills & Experience

- LXC administration
- Linux services
- Shared storage and bind mounts
- Filesystem permissions
- Application integration
- Network service troubleshooting
