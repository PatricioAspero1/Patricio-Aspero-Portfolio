# FlareSolverr

**Type:** LXC Container with Docker  
**Host:** Prometheus  
**Resources:** 1 vCPU / 512 MB RAM  
**Role:** Supporting Web-Request Service

## Overview

FlareSolverr provides a supporting API service for applications within the
self-hosted environment.

The application runs as a Docker container inside a dedicated LXC container,
giving me experience working with multiple layers of containerization and
service integration.

- Service-to-service networking
