# Vanilla Minecraft Server

**Type:** LXC Container  
**Host:** Icarus  
**Resources:** 3 vCPUs / 6 GB RAM  
**Role:** Vanilla Multiplayer Game Server

## Overview

Vanilla is a separate Minecraft server running in its own LXC container.

I intentionally separated the vanilla and modded environments so each server
can be configured, updated, restarted, backed up, and troubleshot
independently.

This provides additional experience with service isolation and resource
management using Linux containers.

## Skills & Experience

- Linux administration
- LXC containerization
- Java server hosting
- Service isolation
- Resource allocation
- Network service administration
