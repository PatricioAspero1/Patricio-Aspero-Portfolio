# Hermes

**Type:** LXC Container  
**Host:** Icarus  
**Resources:** 1 vCPU / 512 MB RAM  
**Primary Role:** Secure Remote Access & Cloudflare Tunnel Gateway

## Overview

Hermes provides remote-access and ingress services for my homelab.

It hosts my Cloudflare Tunnel configuration, allowing selected internal
services to be accessed through individual subdomains without directly
exposing those services to inbound Internet connections.

Hermes also serves as part of my remote-management infrastructure, providing
a centralized location for managing externally accessible homelab services.

## Responsibilities

- Cloudflare Tunnel hosting
- Secure ingress for selected homelab services
- DNS/subdomain integration
- Remote-access infrastructure
- Centralized management of externally published services
- Prometheus Node Exporter monitoring

## Skills & Experience

- Cloudflare Tunnels
- Linux administration
- DNS
- Reverse proxy / ingress concepts
- Remote-access architecture
- Prometheus monitoring
- LXC administration
