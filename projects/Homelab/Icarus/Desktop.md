# Desktop

**Type:** Virtual Machine  
**Host:** Icarus  
**Operating System:** Ubuntu Desktop  
**Resources:** 8 vCPUs / 16 GB RAM / 50 GB Storage  
**Role:** Fallback Remote Administration Environment

## Overview

Desktop is an Ubuntu graphical environment maintained as a fallback
administrative workstation for my homelab.

My normal remote-management workflow relies on secure access from my own
devices. However, there are situations where that access method may not be
available, such as working from a restricted computer where my normal VPN
software cannot be installed.

Desktop provides an alternative management environment from which I can
access administrative interfaces and troubleshoot infrastructure.

## Purpose

- Fallback administrative access
- Remote infrastructure troubleshooting
- Access to internal management interfaces
- Recovery when the primary remote-access method is unavailable

Maintaining a secondary management path reduces my dependence on a single
remote-access method.

## Skills & Experience

- Ubuntu Linux
- Remote administration
- Infrastructure troubleshooting
- Access recovery planning
- Virtual machine administration
